# Fonts

`kosugi-maru-*.woff2` are Kosugi Maru, the font printed on the physical flaps,
so the page draws flaps the way they look. Copyright 2010 The Kosugi Maru
Project Authors (https://github.com/googlefonts/kosugi-maru), licensed under
the Apache License 2.0 (`kosugi-maru-LICENSE.txt`).

They're two of the subsets Google Fonts serves, kept here so the page needs
no internet connection:

- `kosugi-maru-latin.woff2`: Basic Latin and Latin-1 (letters, digits,
  punctuation and °)
- `kosugi-maru-heart.woff2`: the subset that holds ♥ (U+2665)

The `@font-face` rules that use them are at the top of `css/base.css`.
